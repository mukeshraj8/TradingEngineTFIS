# AI Change Instructions

Before making any code, config, script, or documentation change in this
repository, Codex or any other AI coding agent must read and follow:

- `docs/operations/ai_change_agreement.md`
- `docs/operations/project_rulebook.md`

These documents are part of the repository contract. If a user request appears
to conflict with them, the agent must call out the conflict before changing
files.
